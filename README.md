# Codes and Data for the Sierra Nevada Regional Report

This repository contains the MATLAB and R scripts used to generate figures
contributed by Abhishek Chakraborty for the Sierra Nevada Regional Report
of California's Fifth Climate Change Assessment.

## Scripts

- `Figure1p1.m`
- `Figure3p1.m`
- `Figure3p2.R`
- `Figure3p3.m`
- `Figure3p4.m`
- `Figure5p1.m`

## Supporting data

The complete folder structure, including the supporting datasets and large
GeoTIFF files, is available as `Codes.zip` under the latest GitHub Release.

Download the complete archive here:

[Download Codes.zip from the latest release](https://github.com/achakraborty8/Code_C5CCA_SierraNevada_AbhishekChakraborty/releases/latest)

After downloading, extract `Codes.zip`. The scripts expect the supporting
files to remain inside the `Data` folder.

## Software requirements

The scripts require MATLAB or R, depending on the figure.
